
# Product ID Search System

## Project Description
This project implements a Product ID Search System using three different data structures in C programming.

The main objective is to compare the searching efficiency of:
1. Binary Search Tree (BST)
2. AVL Tree
3. Hashing with Linear Probing

## Application
Product Management System

Each product contains:
- Product ID
- Product Name

## Dataset
The project uses 30 unique product records.

## Data Structures Used

### 1. Binary Search Tree (BST)
- Insertion
- Searching
- Inorder Traversal
- Preorder Traversal
- Postorder Traversal
- Tree Height

### 2. AVL Tree
- Insertion with balancing
- LL, RR, LR and RL rotations
- Searching
- Tree Traversals
- Tree Height

### 3. Hashing with Linear Probing
- Hash Function
- Insertion
- Searching
- Collision Handling using Linear Probing
- Collision Counting

## Experimental Analysis
The three methods are tested using the same dataset.

Parameters compared:
- Insertion comparisons
- Successful search comparisons
- Unsuccessful search comparisons
- Tree height
- Hash collisions

Actual experimental observations will be recorded in the Results section.

## Programming Language
C

## Files Included
- bst.c
- avl.c
- hashing.c

## Conclusion
The three data structures are compared based on their searching efficiency, insertion performance, tree height and collision handling. The final recommendation will be based on experimental observations.
